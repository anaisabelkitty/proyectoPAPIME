# Instrucciones del proyecto — Sensei (PAPIME)

## Commits

Sigue siempre la convención de [`docs/commits.md`](docs/commits.md): `<tipo>(<alcance>): <descripción>`, en español, minúsculas, una sola línea, máximo 72 caracteres.

- Cada cambio concreto (un archivo nuevo, una corrección, un ajuste de documentación) se comitea por separado, con su propio mensaje. No juntar varios cambios distintos en un solo commit.
- No commitear automáticamente sin que se pida — se comitea cuando el usuario lo indique, pero ya con el formato correcto sin tener que recordarlo cada vez.
- Antes de comitear, revisar `git status` para confirmar exactamente qué se va a incluir.
